TANISHA DRESSES — Purchase Form Fix

This ZIP contains the updated PWA source files.

Deployment:
1. Extract the ZIP.
2. Upload the contents (index.html, sw.js, manifest.webmanifest, icon.svg) to the existing Netlify site as a new deploy.
3. Keep the same Supabase project and existing business_data row. Do not clear, restore, overwrite, or recreate Cloud data.
4. After deployment, close the old app/PWA fully and reopen the existing site. The service-worker cache version is v6.
5. Open Purchases → New Purchase → choose “Raw Material (80 kg sack)”. Confirm only the relevant fields appear and the total updates automatically.

Important: Do not enter or save a duplicate purchase merely to test the form. The expected test calculation for one 80 kg sack at ₹487/kg is ₹38,960.00.
